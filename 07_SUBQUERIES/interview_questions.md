# Interview Questions

## 1. What is a subquery?

A subquery is a query written inside another SQL query.

---

## 2. When is a subquery executed?

The inner query executes first, followed by the outer query.

---

## 3. Where can subqueries be used?

- SELECT
- INSERT
- UPDATE
- DELETE
- WHERE
- HAVING

---

## 4. What are the types of subqueries?

- Single-row subquery
- Multiple-row subquery
- Correlated subquery

---

## 5. What is the difference between a JOIN and a subquery?

- JOIN combines data from multiple tables.
- A subquery uses the result of one query inside another query.

---

## 6. Can aggregate functions be used in subqueries?

Yes. Aggregate functions such as COUNT(), AVG(), SUM(), MAX(), and MIN() are commonly used in subqueries.
