# SQL Functions

## What are SQL Functions?

SQL functions are built-in operations that perform a specific task on data and return a result.

SQL functions can be broadly classified into:

1. Aggregate Functions
2. Scalar Functions

---

# 1. Aggregate Functions

Aggregate functions perform calculations on multiple rows and return a single result.

Common aggregate functions are:

- COUNT()
- SUM()
- AVG()
- MAX()
- MIN()

---
