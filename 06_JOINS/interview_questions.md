# Interview Questions

## 1. What is a JOIN?

A JOIN combines rows from two or more tables based on a related column.

---

## 2. What is the difference between INNER JOIN and LEFT JOIN?

- INNER JOIN returns only matching rows.
- LEFT JOIN returns all rows from the left table and matching rows from the right table.

---

## 3. Which JOIN returns all records from both tables?

FULL OUTER JOIN.

---

## 4. What is a CROSS JOIN?

It returns the Cartesian product of two tables.

---

## 5. What is a SELF JOIN?

A table joined with itself.

---

## 6. Does MySQL support FULL OUTER JOIN?

No. It can be simulated using UNION of LEFT JOIN and RIGHT JOIN.
